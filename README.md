# Enterprise IAM Governance & Audit Framework

## 🏢 Project Overview
This repository contains a comprehensive **Enterprise Identity & Access Management (IAM) Governance & Audit Framework** designed to enforce access control integrity across cloud infrastructures. 

This project simulates a real-world Governance, Risk, and Compliance (GRC) audit. In this scenario, I act as a GRC Analyst auditing a corporate **Amazon Web Services (AWS)** environment to ensure compliance with the **Principle of Least Privilege**. The project establishes lifecycle policies, maps out functional cloud security roles, logs a mock audit of 50 user accounts, and details the rapid remediation of two critical access anomalies (unterminated ex-employees).

## 🎓 Certifications Applied
* **CompTIA Security+** (Least Privilege, Access Control Models, Identity Lifecycles, Account Auditing)
* **AWS Certified Cloud Practitioner / Security** (AWS IAM Users, Groups, Roles, Policies, MFA Enforcement)

## 📁 Repository Structure
This IAM framework consists of three core compliance deliverables:
1. **[1_IAM_Governance_Policy.md](./1_IAM_Governance_Policy.md):** The formal corporate policy defining strict Service Level Agreements (SLAs) for employee onboarding and offboarding.
2. **[2_AWS_Role_Matrix.md](./2_AWS_Role_Matrix.md):** A technical role-mapping directory establishing baseline AWS permissions per department.
3. **[3_User_Access_Review.md](./3_User_Access_Review.md):** A simulated quarterly audit log catching stale accounts and documenting incident response actions.

## 🧠 Core Competencies Demonstrated
* Identity Lifecycle Governance (Joiners, Movers, Leavers)
* AWS IAM Architecture & Security Best Practices
* Principle of Least Privilege Enforcement
* Access Review Auditing & Compliance Tracking
* Privilege Abuse & Stale Account Remediation
